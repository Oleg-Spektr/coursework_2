# Курсовая работа: Система мониторинга авиапространства

Консольное приложение на Python для интеграции с географическим сервисом OpenStreetMap (Nominatim API) и авиационным трекером OpenSky Network API.

## Архитектура проекта
Программа спроектирована по принципам ООП и SOLID:
- Использованы абстрактные базовые классы (`ABC`) для изоляции уровней данных.
- Обеспечена строгая инкапсуляция и валидация входящих типов.

## Запуск приложения
1. Установите зависимости проекта:
   ```bash
   poetry install --no-root
   ```
2. Запустите главное меню:
   ```bash
   python main.py
   ```

## Тестирование и линтинг
- Запуск тестов с проверкой процента покрытия кода (критерий >=70%):
  ```bash
  poetry run pytest --cov=src tests/
  ```
- Проверка кода на соответствие PEP 8:
  ```bash
  poetry run flake8 src/
  ```
